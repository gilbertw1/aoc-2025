# Input Data Directory

This directory contains the input files for each day of Advent of Code 2025.

## File naming convention

Input files should be named as `dayXX.txt` where XX is the day number with leading zero:
- `day01.txt` for Day 1
- `day02.txt` for Day 2
- `day25.txt` for Day 25

## Getting your inputs

1. Go to [Advent of Code 2025](https://adventofcode.com/2025)
2. Log in to your account
3. Navigate to the day you want to solve
4. Copy your personal input
5. Save it to the corresponding `dayXX.txt` file in this directory

**Note:** Input files are personal and should not be committed to public repositories per AoC rules.
